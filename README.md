# Quiz Tracker

A simple and intuitive web application for tracking quiz scores across multiple subjects. Organize your quiz results by subject (Math, Business, Research, Data Analytics) and easily manage your academic progress.

## Features

- 📊 **Subject-based Organization**: Track quizzes for Math, Business, Research, and Data Analytics
- ➕ **Easy Entry Addition**: Add quiz scores with name, score, and date
- 🗑️ **Quick Deletion**: Remove entries with a single click
- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- 💾 **Real-time Updates**: See changes instantly without page refresh

## How to Use

1. **Select a Subject**: Choose from the dropdown menu (Math, Business, Research, or Data Analytics)
2. **Enter Quiz Details**:
   - Quiz Number/Name (e.g., "Quiz 1" or "Algebra")
   - Score (0-100)
   - Date
3. **Click "Add Entry"**: Your quiz score will be added to the appropriate subject table
4. **View Results**: Check the corresponding subject sheet for all your quiz entries
5. **Delete Entries**: Use the Delete button to remove any quiz entry
